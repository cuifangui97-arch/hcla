# Story build inputs

These maintained files are read by the story generator and the EP09 runtime module. Keep them in sync with the accepted story corpus when updating generated `stories/template/story.json`.

The original delivery bundles and reference materials remain in the developer's local `source_package/` directory and are gitignored. They are not required for a clean checkout to build the project.

Story content is separate from the MIT-licensed application code. Before publishing this repository, confirm that the story text and all bundled media may be redistributed publicly.
